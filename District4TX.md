A fast, mobile-first, single-file campaign page that puts young Americans first with bold policy, animated counters, and zero bloat.

- 100% one HTML file  
- Animated impact counters on scroll  
- Sticky header + hover effects  
- Fully responsive  
- Instantly updates when you upload a new index.html  
- Deploys free forever on GitHub Pages  

### Files

- `.nojekyll` → required so GitHub doesn’t break the styling  

### How to Update (30 seconds)
1. Edit `index.html`  
2. Drag & drop the new version here  
3. Commit → live worldwide instantly
